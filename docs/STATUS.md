## 今晚查清的事实

屏幕（来自仓库里的数据手册，DKE DEPG0397BBS77AF11HP）：

- 3.97 寸，480×800，235 DPI，显示区 51.84 × 86.40 毫米。
- 屏厂只保证黑白两级；出厂波形整屏全刷 3.2 秒（25℃）；工作温度 0 到 50℃。
- 对比度约 7:1，白底反射率 30%，真屏没有纯白纯黑。
- README 和代码注释写的是 GDEM0397T81，和数据手册不是同一家，到货后看排线标签确认。

官方驱动（`Metalio-E-INK4/main/display/LUT/` 和 `esp_lcd_panel_ssd1677.c`）：

- 局刷波形 17 帧（注释标 50 Hz，约 0.34 秒），并留有改成 100 Hz 的注释。
- 快速全刷 40 帧（约 0.8 秒）。
- 看书模式的抗锯齿是“黑白底图加灰度叠加”，叠加这一遍 12 帧，只有白、浅灰、深灰、黑四档。
- 以上耗时都是按波形表算的，没有实测。

文字渲染（`tools/fontbench/` 里的脚本可以重跑）：

- 浏览器画的示意稿有灰度平滑，比真机好看，不能拿来判断清晰度。
- 纯黑白要用 FreeType 的黑白栅格器。没有像素对齐信息的字体（MiSans、思源黑体）必须强制自动对齐，否则笔画忽粗忽细。
- 更纱黑体自带像素对齐信息，纯黑白下最整齐，OFL 许可可以随固件分发。
- 字重用常规体；中等字重在 20 号下笔画多的字会糊。

会话数据（`tools/transcript-shape.mjs` 可以重查）：

- Claude Code 的会话记录里有模型名、每一步的工具和文件路径、每次修改的逐行补丁、说明文字、git 分支和 token 用量。
- Codex 的记录格式还没核对。

## 第 5 项：假 agent 和电脑端服务（已完成）

界面的数据现在从网络来，跟着剧本变化。协议在 `docs/PROTOCOL.md`。

电脑端（`bridge/`，TypeScript，Node 直接运行，不用编译）：

- `npm run demo` 起服务和假 agent，同一个端口（8137）提供仿真器页面。只监听本机地址；检查 Origin，别的网页连不进来。
- 假 agent 有六个会话的剧本（`src/fake/scenario.ts`），开场的计数、文件、改动片段由回放历史生成，所以对得上：
  - codetalky 等批准。批准后改文件、补测试、提交；拒绝后换个小改动再问；10 分钟没人理就当拒绝。
  - blog-engine 等回答，三个选项各走各的。
  - firmware 在跑，测试先失败再修好，最后请求 `git push`，要长按批准。
  - landing 在跑，自己做完。
  - api-server 已完成；回复“继续下一步”会接着做前端分页，五句快速回复各有对应的动作。
  - docs-site 出错停着，不能从设备发指令，50 秒后自己恢复。
- 31 个测试（`npm test`），用假时钟，跑一遍不到一秒。剧本里每段代码都检查过不超出屏宽（37 个字符）。

设备端（`ui/`）：

- `ct_proto.c` 用 cJSON 解析消息、拼出动作；`ct_model.c` 存会话，每个会话一块独立内存（`ct_arena.c`），新快照整块替换。
- 排序：等你的在前（等得最久的最前），然后出错、完成、运行中、空闲；同一类按名字排，免得行在屏幕上跳来跳去。
- 界面按会话号找会话，不跨更新保存指针。数据变了每 200 毫秒查一次，手指按着时不画，两次至少隔 600 毫秒，用局刷，每 12 次换一次快刷；重新同步后第一次画用快刷。
- 点了批准、回答、发指令后等电脑的回执再回列表，只刷一次屏；2 秒没回执或被拒绝，列表底部显示一行原因。
- 批准页：`risky` 的请求要长按 0.6 秒，单击只震一下；命令直接显示整条，不显示改动。正在看的请求在别处被处理了，自动离开批准页。
- 有会话开始等你时震动 150 毫秒。
- 没连上、正在同步、没有会话、版本不一致，各有空状态页；不能发指令的会话不显示“发指令”和“回复”。
- “读 12 · 改 4”“等了 2 分”“14:40 前没批准，就要回电脑确认”这类文字由设备根据数字和时间戳拼；状态栏时间来自电脑。

仿真器：

- 网页连 `ws://<同一地址>/device`，断了 2 秒后重连，右侧显示连接状态。
- `snapshot.mjs` 在同一个进程里跑电脑端服务和假 agent，时钟从 2026-11-14 14:32（东八区）开始，结果可重复。新加 `--hold x,y`（长按）、`--offline`、`--verbose`。
- `simulator/tools/render-ui.sh` 一次出全部 13 张图到 `design/renders/ui-*.png`，包括批准后的列表、长按批准页、出错页、没连上电脑。

接真机时要做的（固件还没开始）：`ct_hal_net_send()`、`ct_hal_battery_percent()` 两个函数；收到的消息要在界面线程里交给 `ct_ui_on_message()`；cJSON 用 ESP-IDF 自带的同一个版本；会话内存走 `malloc`，要开 PSRAM 分配。
